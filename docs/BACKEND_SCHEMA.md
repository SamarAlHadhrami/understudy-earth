# BACKEND SCHEMA (static files in app/data)
- `earth.json`: per 10 km window {id, group, lat, lon, hist (slope x roughness counts), slope_p50, slope_p90, steep_share, rough_med, rough1k_med, relief_m}.
- `targets.json`: same fields for Moon/Mars targets plus body, name.
- `meta.json`: bin edges, term scales, rank cut-offs, thr_match_dist, thr_partial_dist, task note (slope limit is user-set).
- `results.json`: gap table, name-free check, leave-one-out sensitivity, scales.
- `second_check.json`: independent slope check rows.
- `climate_power.json`: {cells: {key: {lat, lon, T2M, T2M_MAX, T2M_MIN, WS2M, RH2M, PRECTOTCORR, ALLSKY_SFC_SW_DWN (12 months each)}}, win: {window id: cell key}, source, accessed}.
- `baseline.json`: {rows: per target, per known site: rank vs random draws; summary}. Built by `pipeline/baseline.py`.
- `stability.json`: {configs, summary: per target tiers seen, rank band, threshold_sensitive}. Built by `pipeline/stability.py`.
- `landcover.json`: {window id: [tree %, crop %, built %]} from ESA WorldCover 2021 v200. Built by `pipeline/landcover.py`. `mask_check.json`: tier change when flagged squares are hidden.
- `relief/<id>.png`: 64 x 64 shaded relief per window and target, built by `pipeline/relief.py` (about 1.4 MB for 644 files).

# APP FLOW
1. Planner tab (first view): map of Oman squares. Left of panel: choose the Moon/Mars target, then describe the test with a ready-made button, the sentence box (or mic), or sliders. The map recolours live.
2. Map mode: where+when (default), terrain only, or needs only. Month: best month per square or a chosen month.
3. Gap card: best terrain match in Oman with MATCH/PARTIAL/GAP; tick Meteor Crater or Atacama to add a second site and see the tier change.
4. Click a square: tier, best months, 12-month strip, metrics vs target, slope chart, confidence, limits box; buttons: Test Site Brief, Compare.
5. Test Site Brief: full-page view, Print / save as PDF.
6. Gap view: all targets, Oman only vs plus check sites.
7. Blind test view. AMADEE-18 replay view (planner vs the real February 2018 phase). How it works view.
8. Share link: choices are stored in the address (#t=...&tlo=...).

# APP FLOW
1. First view: dark map of the Oman tiles, windows coloured by score for the default task (rover) and default target. One line says what the user is looking at.
2. Task selector (rover; walking/landing only if limits are sourced). Target selector: Moon/Mars targets (Jezero, Gale, ...). Click-on-Mars is an extra.
3. Slider: max slope limit; the map recolours live from the histograms.
4. Click a window: score, short reason (slope, roughness, traversable share), limits box.
5. Gap view: per target best Earth score, red/green, "add second site" toggle (Meteor Crater, Atacama) turns red to green when it closes.
6. Blind-test view: ranks of known sites, misses shown.
7. Panels: How it works; What Earth cannot copy.

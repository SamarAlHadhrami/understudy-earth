# UI/UX BRIEF
Direction: mission control meets clean data story. Dark navy, teal/amber tiers, muted rose hatch for WEAK, slate grey for "no qualifying candidate", monospace numbers.
Colour-blind safe: WEAK squares and months use a hatch pattern, partial months use dots, good are solid; every month cell carries a number and a symbol (star best, tick good, ~ partial, x poor); legend uses words.
Layout: desktop = map left, panel right; phone = map on top, panel below, no horizontal scroll (tested at 390 px).
States: loading error message; empty result hint; no-candidate calm card; refused sentence message.
Print: Test Site Brief has its own print stylesheet (white, one page).
Result card order: Fit Verdict (overall %, factor bars, weight sliders; labelled user-weighted soft score), 12-month strip with notes, metrics, slope chart, twin pictures (own 5 km scale bar under each picture, native resolution in caption), confidence, limits.
30 s demo path: see DEMO_SCRIPT.md.
Footer carries the OpenStreetMap (ODbL), WorldCover (CC BY 4.0) and data credits. Geology notes use a blue-edged box (notes, not a score). 90 m squares are thinner-outlined and labelled coarser.
